# じゃんけんバトル 仕様書 v1.0

実装計画は `PLAN.md` を参照。

---

## 1. ゲーム概要

じゃんけんの三竦みを相性とした、1対1交代制の2人対戦ゲーム。

- 各プレイヤーは全15種から **5体のパーティー**を編成する
- 対戦開始時、両者のパーティー5体を **相互に公開**する
- そこから **3体を選出**する(選出内容は相手に非公開)
- 場に出るのは各陣営1体。相手の選出3体すべてを撃破した側が勝利

### 対戦モード

| モード | 内容 |
|---|---|
| **AI戦** | プレイヤー vs CPU |
| **対人戦** | 同一端末での交互操作(ホットシート) |

両モードとも行動は同時宣言。対人戦では入力の秘匿処理が必須(→ §10)。

---

## 2. 属性と相性

属性は `グー` / `チョキ` / `パー` の3種。

```
グー > チョキ > パー > グー
```

相性補正はダメージへの**加算**として扱う。

| 相性 | 補正 |
|---|---|
| 有利 | **+25** |
| 互角 | **±0** |
| 不利 | **−10** |

設計上の想定撃破速度(威力25・HP100基準):

| 相性 | 1発のダメージ | 撃破まで |
|---|---:|---:|
| 有利 | 50 | 2発 |
| 互角 | 25 | 4発 |
| 不利 | 15 | 7発 |

---

## 3. ステータス

| 項目 | 内容 |
|---|---|
| HP | 40〜140 |
| 速度 | `速` / `中` / `遅` の3段階(内部値 3 / 2 / 1) |
| 技枠 | 2枠。「技2つ」または「技1つ + 特性1つ」 |

**特性は場に出ている間のみ発動する。** 控えでは一切機能しない。

---

## 4. ダメージ計算

### 4.1 通常ダメージ

```
最終ダメージ = max(0, 技威力 + 相性補正 + 攻勢修正(攻撃側) − 守勢修正(防御側))
```

**ダメージ下限は 0**(負の値にはならない)。

### 4.2 固定ダメージ

以下は `固定` ダメージとして扱い、**相性補正・攻勢修正・守勢修正のすべてを無視**する。表記どおりの値がそのまま適用される。

- 手のひら 技1(固定20)
- 毒(10)
- 設置(10)
- 反動(粉砕30 / 石15 / ゴースト5)
- 反射(山嵐10 / ゴースト40)

### 4.3 修正値(バフ・デバフ)

対象は **攻勢 / 守勢** の2軸。実数値で加算する。段階制は用いない。

持続期間は技ごとに定義される。2種類のみ存在する。

| 持続 | 内容 | 該当技 |
|---|---|---|
| `このターン` | 宣言したターンの解決中のみ有効 | はさみ 技2(守勢+10) |
| `交代まで` | 交代または瀕死までの永続 | 一閃 技2(攻勢+15) |

- **累積上限は +30(2回分)まで。** 3回目以降の使用は無効
- 交代・瀕死でリセットされる
- 守勢修正は **相手の技によるダメージにのみ**適用される。固定ダメージ(§4.2)には適用されない

## 5. ターン進行

### 5.1 行動宣言

両プレイヤーが同時に行動を宣言する。選択肢は以下のいずれか。

- 技1 を使う
- 技2 を使う
- 控えの生存ユニットに交代する

### 5.2 優先度

```
[1] 交代
[2] 先制技
[3] 通常技 … 速 → 中 → 遅
```

**同段は「同時」に処理される。**

- `[1] 交代` に両者が入った場合 → 同時
- `[2] 先制技` に両者が入った場合 → **速度に関係なく同時**
- `[3] 通常技` は速度で3段に分かれ、同速なら同時

### 5.3 同段内の処理順

同段に入った行動は、以下の3ステップで解決する。

```
ステップ1: ダメージ計算
    守勢 → 回復 → 攻勢 → 反動 → 反射 の順に数値を確定させる
    (この時点では HP を変動させない)

ステップ2: ダメージ処理
    確定した数値を同時に適用する

ステップ3: 強制交代処理
    団扇による強制交代、魔球による自己交代
```

同時適用のため、**相打ち(両者同時に瀕死)が発生しうる**。

### 5.4 瀕死判定

**HPの変化があるたび**に瀕死判定を行い、瀕死時特性を処理する。

```
HP変化 → 瀕死判定 → 瀕死時特性の発動
```

### 5.5 攻撃対象が既に瀕死の場合

先の段で対象が瀕死になっていた場合、後の段の攻撃は**不発**となる(何も起こらない)。

例: 速の攻撃で遅のユニットが瀕死 → その遅ユニットの通常技は発生しない。

### 5.6 ターン終了処理

```
1. 毒(固定10 × スタック数) → 瀕死判定
2. 回復(堅牢の特性など)    → 瀕死判定
```

**毒が回復より先。** 毒で瀕死になったユニットは回復されない。

毒ダメージは **場に出ているユニットのみ**が受ける。控えの毒ユニットは減らない。

### 5.7 瀕死ユニットの交代(死に出し)

- **ターンの全処理(§5.6を含む)が完了した後**にまとめて処理する
- **ターンを消費しない**
- 交代先はプレイヤーが選択する
- **死に出しでも設置を踏む**
- 設置ダメージで死に出したユニットが即瀕死になった場合、再度死に出しを行う(連鎖)

この順序により、**死に出しで登場したユニットが同一ターン中に攻撃されることはない。**

---

## 6. 交代

- 優先度は最上位(§5.2)
- **交代したターンは、交代先のユニットが被弾する**
- 交代で **修正値・累積カウントがリセット**される
- **毒は交代しても維持**される(ユニット単位で保持)
- 交代で場に出るたび、自陣の設置ダメージを踏む
- 控えに生存ユニットがいない場合、交代は選択できない

---

## 7. 特殊状態

### 7.1 毒

| 項目 | 内容 |
|---|---|
| 効果 | ターン終了時に固定10ダメージ |
| 保持 | ユニット単位。交代しても維持される |
| 重複 | **3重まで**。3重で30/ターン。4重目の付与は無効 |
| 対象 | 場に出ているユニットのみ減少する |
| 解除 | 手段なし |

### 7.2 設置

| 項目 | 内容 |
|---|---|
| 効果 | 相手側の場に設置。相手のユニットが場に出るたび固定10ダメージ |
| 発動 | 通常交代・強制交代・死に出しのすべてで発動 |
| 重複 | **3枚まで**。3枚で30ダメージ。4枚目の設置は無効 |
| 解除 | 手段なし |

### 7.3 累積カウント

`使うたび` 系の技は使用回数を保持する。**交代でリセット**される。

| ユニット | 技 | 挙動 |
|---|---|---|
| 魔球 | 技1 | 威力 30 → 20 → 10 → 0(下限0) |
| カマキリ | 技1 | 威力 15 → 20 → 25 → …(上限なし) |

### 7.4 反射

| 項目 | 内容 |
|---|---|
| 発動条件 | **攻撃技によるダメージを受けた場合のみ** |
| 非発動 | 毒・設置・反動によるダメージでは発動しない |
| 連鎖禁止 | **反射ダメージは反射を誘発しない**(構造的に禁止する) |

ゴーストの瀕死時反射は例外として、**死因を問わず**発動する(通常攻撃・毒・設置・反動のいずれでも)。反射先は相手の場にいるユニット。

## 8. 勝敗

- 相手の選出3体すべてを撃破した側の勝利
- **最後の1体同士が相打ちになった場合は引き分け**
- ターン上限は設けない

## 10. 個別ユニットの詳細仕様

実装時に判断が必要な箇所を、すべてここで確定させる。

### 10.1 粉砕(最も処理順に敏感)

技1の解決順を厳密に以下とする。

```
1. 相手へのダメージを適用
2. 相手の瀕死判定(自分の攻撃で倒したか)
3. 倒していれば → 反動を無効化 / 倒していなければ → 自分に反動30を適用
4. 自分の瀕死判定
```

**「倒した」とは自分の攻撃で倒した場合を指す。** 相手が自分の反動で自滅した場合や、反射で落ちた場合は含まない。

**帰結:**

- 撃破成功 → 反動を受けない。それまでに削られたHPはそのまま残る
- 撃破失敗 → 反動30。HP60なので**満タンからでも2回目で自滅する**(60 → 30 → 自滅)
- 撃破失敗しても即死はしないため、**1回は空振りが許される**

| 相性 | 威力 | 一撃で倒せる相手 |
|---|---:|---|
| 有利 | 85 | 大半 |
| 互角 | 60 | HP60以下(粉砕ミラー・鉄拳) |
| 不利 | 50 | HP50以下 |

有利対面では大半の相手を一撃で倒せるため、**倒し続ける限り無傷で殴り続けられる**。

威力60 が互角対面のHP60 に届くため、**粉砕ミラーは相打ちの引き分けになる**(双方が同時に倒れ、反動は無効化されるが既にHPは0)。永久に決着しない状態は生じない。

**注意:** 反動無効は「回復」ではないため、**カマキリの治癒封じ(§10.6)では止められない**。

### 10.2 鉄拳(追い討ち)

技2は通常技優先度(中)。**相手がそのターンに「交代」を宣言していた場合**、威力に+20する。

- 交代は優先度[1]で先に解決されるため、**ダメージは交代後に出てきたユニットに入る**
- 相性判定も交代後のユニットに対して行う
- **団扇の強制交代・魔球の自己交代では追い討ちは発動しない**(これらはステップ3で解決され、鉄拳の攻撃より後になるため)
- 死に出しによる交代でも発動しない

### 10.3 魔球

- **技1:** 使用ごとに威力−10。下限0(0になっても使用可能、ダメージは相性補正のみ)。交代でリセット
- **技2:** 威力15を与えた後、自分が交代する。交代先はプレイヤーが選択する
  - ステップ3(強制交代処理)で解決する
  - 控えに生存ユニットがいない場合、**攻撃のみ行い交代しない**
  - 交代先は自陣の設置を踏む

### 10.4 堅牢

ターン終了時にHP5回復(§5.6の順序に従い、毒処理の後)。HPが満タンなら何も起こらない。

### 10.5 石 / ゴースト(反動)

反動は固定ダメージ。攻撃が不発だった場合(対象が既に瀕死 → §5.5)、**反動も発生しない**。

### 10.6 カマキリ(回復無効)

カマキリが場に出ている間、**相手側で発生するあらゆる回復を無効化**する。

対象となる回復:

- 手のひら 技2(自分のHP25回復)
- 器 技2(控えのHP15回復)
- 堅牢の特性(ターン終了時5回復)

技や特性自体は発動するが、回復量が0になる(ターンは消費される)。

**粉砕の特性(§10.1)は対象外。** 反動の無効化であって回復ではないため、治癒封じでは止められない。

### 10.7 山嵐(反射)

攻撃技によるダメージを受けたとき、攻撃してきたユニットに固定10を返す。

- 毒・設置・反動によるダメージでは発動しない
- 反射ダメージは反射を誘発しない(山嵐同士の対面でループしない)
- ダメージが0だった場合も、攻撃技を受けていれば反射する

### 10.8 バラ

- **技1:** ダメージなし。相手に毒を1スタック付与。既に3重なら無効(ターンは消費)
- **技2:** ダメージなし。相手側の場に設置を1枚追加。既に3枚なら無効(ターンは消費)

### 10.9 一閃(積み)

技2は攻勢+15を付与。交代または瀕死までの永続。**累積上限は+30(2回分)**。3回目以降の使用は無効(ターンは消費)。

| 積み回数 | 技1の実効威力 | 有利対面 | 互角対面 |
|---:|---:|---:|---:|
| 0 | 35 | 60 | 35 |
| 1 | 50 | 75 | 50 |
| 2 | 65 | 90 | 65 |

HP40のため、**威力15の有利対面(40)で一撃で落ちる**。積みは常に博打として機能する。

### 10.10 はさみ

技2は威力10を与えつつ、このターンの自分の守勢+10。速度が `速` のため、相手より先に修正値が乗る。

- **相手の技によるダメージのみ**を10軽減する
- 固定ダメージ(手のひらの固定20 / 毒 / 設置 / 反射)は軽減できない

### 10.11 手のひら

- **技1:** 固定20。相性補正・修正値をすべて無視する
- **技2:** 自分のHP25回復。HP満タンなら何も起こらない(ターンは消費)
  - **使用回数は1試合につき3回まで。** 使い切ると技として選択できなくなる
  - この回数は**交代でリセットされない**(§7.3 の累積カウントとは別扱い)
  - 回復の応酬による膠着を防ぐための制限

### 10.12 ゴースト(瀕死時反射)

瀕死になったとき、相手の場にいるユニットに固定40を与える。

- **死因を問わない**(通常攻撃・毒・設置・自分の反動のすべてで発動)
- 相打ちの場合も発動する
- この反射で相手が瀕死になった場合、相手も死に出しを行う

### 10.13 器

技2で控えの生存ユニット1体を選択し、HP15回復。

- 選択できるのは生存している控えのみ
- 控えが全員瀕死、または全員HP満タンの場合も技は使用可能(何も起こらず、ターンを消費)
- **控えのユニットは場にいないが、回復は成立する**(特性ではなく技であるため)

### 10.14 団扇

技2で相手を強制交代させる。

- 交代先は相手の**生存している控えからランダム**に決定する
- ステップ3(強制交代処理)で解決する
- 相手の控えに生存ユニットがいない場合、何も起こらない(ターンは消費)
- 交代先は相手側の設置を踏む
- **本ゲームで乱数を使用する唯一の箇所**

### 10.15 紙

技2は威力15の先制技。両者が先制技を使った場合、速度に関係なく同時処理(§5.2)。

## 11. 対人戦(ホットシート)の入力秘匿

同時宣言のため、以下のフローを必須とする。

### 選出フェーズ

```
1. 「プレイヤー1の選出です」確認画面
2. P1が3体を選出 → 選出内容を画面から消す
3. 「プレイヤー2の選出です」確認画面
4. P2が3体を選出
```

**パーティー5体の相互公開(§1)は選出画面が兼ねる。** 選出画面は両者の編成を並べて出すため、
公開のためだけの画面は置かない。ただし**相手がどの3体を選んだかは出さない**。

### 各ターン

```
1. 「プレイヤー1の入力です」確認画面(タップで開始)
2. P1が行動を宣言 → 入力内容を画面から消す
3. 「プレイヤー2の入力です」確認画面
4. P2が行動を宣言
5. 「2人とも画面を見ていますか?」確認画面
6. 両者の行動を同時公開し、ターンを解決
```

5 は**両者が解決を見届けるため**の確認。片方が宣言した直後に解決を始めると、
端末を持っていないもう一方が何が起きたのかを見逃す。死に出しの解決前にも同じ確認を挟む。

**確認画面で盤面を隠さない。** 隠すのは行動宣言の内容だけであり、
盤面まで消すと解決を見終わった瞬間に結果が画面から消えてしまう。

盤面情報(HP・毒スタック・設置枚数・修正値・場のユニット)は両者に公開してよい。
**隠すのは「当該ターンの行動宣言」と「相手の控えの中身」のみ。**

一度場に出たユニットは、控えに戻っても情報(残HP・毒)を公開し続ける。

### 対AI戦

**「相手の控えの中身」の秘匿は、対戦相手が人間かAIかを問わない。** パーティー5体は選出前に
相互公開されるが、そこから選ばれた3体が何かは別の情報であり、公開しない。プレイヤーから見える
相手の控えは、上と同じく「一度場に出たもの」だけ。

行動宣言の秘匿は不要(相手はAIであり、画面を覗く相手がいない)。
